What the server is running

If scans look wrong, check this first: a missing CLIP head or a disabled vision provider explains most “it guesses badly” reports.

Quick checks

  • confidence_threshold — below this the app shows “not sure” and asks a follow-up.
  • clip.enabled=false — batteries, chargers, bulbs and syringes will be guessed badly.
  • vision.enabled=false — unknown objects fall back to mixed_trash. Add GEMINI_API_KEY to name anything.
  • image_storage=false — the Photo column stays empty by design (privacy). Enable Cloudinary to review images.
